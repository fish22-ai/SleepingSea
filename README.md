# 睡前水族馆 🐟

一个放在手机桌面上的睡眠自律小应用：**今晚几点睡，明天的鱼缸说了算。**

达成计划的夜晚，鱼缸里会多一条鱼、水草更绿、珊瑚更艳；
破例的夜晚，第二天水会发灰、水草枯萎、珊瑚褪色，已有的鱼也会变灰变蔫。

---

## 一、怎么装到荣耀手机桌面上

这个项目是一个 **PWA**（渐进式 Web 应用）。真正的 Android 原生小组件需要写 Kotlin + Android Studio 打包 APK，这里给的是最接近的替代方案：**加到主屏幕的独立应用**——有自己的图标、名字，点开是全屏界面，没有地址栏，完全离线可用，数据存在手机本地。

**线上地址（GitHub Pages）：**

```
https://fish22-ai.github.io/SleepingSea/
```

**步骤：**

1. 用 **荣耀浏览器** 或 **Chrome** 打开上面这个链接（第一次打开会从 GitHub 拉资源，稍微等一下）；
2. 等页面正常显示鱼缸后，点浏览器菜单 → **添加到主屏幕 / 安装应用**；
3. 桌面会出现一个水族馆图标（像素小丑鱼），点开就是全屏应用，之后**断网也能开**。

> 也可以先把项目跑在电脑上（见下文「本地预览」），手机浏览器访问 `http://电脑局域网IP:8080`，一样能加到主屏幕——但电脑关机后就打不开了，所以日常用还是用上面的 Pages 地址。

> 手机重启后第一次打开会有一瞬间加载，之后 Service Worker 会直接从本地缓存读，秒开、零流量。

### 图标是怎么来的

`icons/` 下的四张图（圆角 192 / 圆角 512 / 满幅 maskable 512 / iOS 用的 192）都是由 `tools/make_icons.py` 生成的：先在一个 **32×32 的低分辨率网格**上把小丑鱼、水草、沙地画出来，再按整数倍最近邻放大——所以图标和 App 里的鱼缸是同一套像素语言。想换配色或改动构图，改脚本里的颜色常量和场景元素表，再跑一次 `python tools/make_icons.py` 即可。

### 想要桌面上能看到「会动的鱼」？

PWA 做不到桌面常驻动画。变通方案：

- 用 `widget.html`（本目录里那个精简版，只有鱼缸 + 鱼数 + 按计划睡天数）配合手机上的**网页小组件**类 App（比如「Web Widget」「小组件盒子」这类）把它嵌到桌面上，就能实现一个能自动刷新的桌面鱼缸；
- 或者干脆就用主屏图标，睡前点进去看一眼鱼，这个动作本身就是仪式感的一部分。

## 二、怎么用

### 睡前（第一次）

1. 打开应用 → 点底部 **「设置」**（打开的其实就是「今晚几点睡」这一页）；
2. 选 **打算几点睡着**（预估睡眠时间）和 **明早几点起**；
3. 拖动滑块选 **提前多久熄灯**（默认 30 分钟，比如打算 23:00 睡，22:30 就锁定）。

**改完即生效，没有保存按钮**——「今晚的安排」卡片会立刻变成「已生效 ✓ 今晚 22:30 自动熄灯（还有 3 小时 12 分）」，到点页面自动锁住；之后想改时间直接改就行，会覆盖上一版计划。

> 如果打开这一页时**今天的熄灯时间已经过了**，不会突然把页面锁住，只会提示「今天已经过了熄灯时间」：要么把入睡时间改到之后，要么现在躺下直接点首屏的「晚安 🌙」。

> **赶时间？** 直接点首屏的 **「晚安 🌙 开始潜水」**——不用填任何东西，按下瞬间就锁屏进入睡眠模式，按今晚已有计划（没计划就用默认时间）倒计时到起床。白天（6:00–19:00）按下会先确认一次，防止误触。

底部 **「图鉴」** 打开「睡前图鉴 · 梦境生灵」，共 12 种海底生物：

| 生物 | 稀有度 | 点亮条件 |
|---|---|---|

| 霓虹灯鱼 | 常见 | 累计记录 3 夜 |
| 小金鱼 | 稀有 | 连续 2 晚按计划睡 |
| 神仙鱼 | 稀有 | 累计 5 晚达成 |
| 孔雀鱼 | 史诗 | 累计记录 10 夜 |
| 蓝倒吊 | 史诗 | 历史最长连续 5 晚 |
| 粉小丑 | 传说 | 累计 12 晚达成 |
| 海马 | 稀有 | 连续 4 晚按计划睡 |
| 灯塔水母 | 稀有 | 连续 6 晚按计划睡 |
| 鱿鱼 | 史诗 | 累计记录 20 夜 |
| 河豚 | 史诗 | 累计 10 晚达成 |
| 章鱼 | 传说 | 累计记录 30 夜 |

每点亮一种，**它就会真的游进你的鱼缸**。结算完成后自动检查点亮，首屏会弹提示。

### 画风

整个鱼缸是 **16-bit 像素风**：青绿色分层水色、顶部水面波光、横贯全底的草皮与短水草、三颗苔藓球、两侧管珊瑚与红枝珊瑚、手工绘制的像素鱼精灵（12 种，摆尾 / 触手都有动画）。没有岩石和光柱，是一整片平铺开的种植缸。守得好颜色鲜艳，破例了整缸发灰褪色。

鱼的游速刻意调得很慢（约是早期版本的一半），摆尾频率、转向幅度和上升气泡也一并放轻，看着更像在水里慢慢呼吸，而不是赶路。想再快点或再慢点，改 `js/aquarium.js` 里 `step()` 的 `base`（当前 19）即可。

鱼缸有 **日间 / 夜间** 两套光照：日间是明亮薄荷水色 + 暖阳光斑 + 奶黄沙地，夜间是藏青海水 + 月色冷光 + 发光浮游生物 + 冷绿植物。默认 06:30–18:30 自动切日间，其余时间夜间；首页右上角的胶囊可以随时手动切换或固定成某一种。熄灯锁定时会在夜间基础上再压暗一层。

### 锁定后

- 页面变成深色熄灯界面，只显示倒计时和鱼缸的当前状态；
- 想解锁：**点一下「解锁」按钮**就行（半夜急用手机不至于跟它搏斗），理由会自动记档；
- 每一次解锁都会原样记进档案，**而且不会被后来的操作抹掉**。解锁之后想继续睡，再点一次首屏的「晚安 🌙」就重新进入睡眠模式（这一笔同样记在档案里）。

### 第二天

- 到起床时间后，昨晚的结果自动结算，只有两种结果：
  - **达成**（整夜 0 次解锁，且没有明显晚睡）→ 鱼 +1，水色 +，灰暗 −，水草珊瑚生长，所有灰鱼复活；
  - **未达成**（解锁过，或者补记的真正入睡时间比计划晚 40 分钟以上）→ 不加鱼，水色下降，灰暗上升，水草珊瑚蔫一点，一条鱼变灰。
- 晚睡超过 40 分钟就够判未达成了（阈值是 `js/store.js` 顶部的 `LATE_LIMIT_MIN`），不存在「轻微破例」这种中间档。
- 水色的灰暗度是累积的，按计划睡几晚就会自己清回来。

### 睡眠档案

底部「记录」进入睡眠档案，全部是大白话，不看说明也看得懂：

- 顶部四个数：**连续按计划睡觉 · 平均睡眠 · 达成夜 · 条鱼**；
- 中间一张「最近 7 天，每晚睡了多久」柱状图：柱子高度就是实际睡眠时长，虚线是 8 小时参考线，绿=达成、红=未达成；
- 下面「每一晚」列表：每一行写清 `<入睡> 睡 · <起床> 起 · <共几小时>`，配一个状态标签；有解锁会列出具体时间，有补记的还会显示「原计划 X 睡，实际 Y」；
- 点任意一行可以补改时间，改完自动重新判定；「＋ 补记一晚」手工补一条。

## 三、本地预览 / 部署

```bash
# 任选一种，在项目根目录执行
python -m http.server 8080
npx serve .
```

然后浏览器打开 `http://localhost:8080`。

> 直接双击 `index.html` 也能用（此时 Service Worker 不生效，数据仍保存在 localStorage），但「安装到主屏幕」需要 http/https，所以正式使用建议走服务器。

电脑上打开时会自动变成一个居中的「手机比例」窗口，方便先在桌面上试试手感；手机上打开则是全屏。

### 自动部署到 GitHub Pages

仓库地址：<https://github.com/fish22-ai/SleepingSea>

推送到 `main` 分支后，`.github/workflows/pages.yml` 会自动做三件事：

1. `node tools/test_store.js` + `node tools/test_migrate.js` —— **测试挂了就直接不部署**，不会把坏版本推到手机上；
2. 把 `index.html / widget.html / manifest.webmanifest / sw.js / css / js / icons` 打成一个干净的产物（`.shots/`、`.design/`、`tools/` 不会进网站）；
3. 发布到 GitHub Pages，地址 <https://fish22-ai.github.io/SleepingSea/>。

日常改动流程就是：

```bash
git add -A && git commit -m "改了什么" && git push
```

等 Actions 跑完（约半分钟），手机上把应用关掉重开即可拿到新版本。

> **改了前端资源记得 bump `sw.js` 里的 `CACHE` 版本号**，否则手机上是旧缓存。SW 本身是「网络优先」，正常情况下刷新就能拿到新文件，bump 版本号只是保险。

## 四、数据存在哪 / 会不会丢

- 所有数据都在浏览器 `localStorage` 里，**不上传任何服务器，没有网络请求**（Service Worker 缓存除外）。
- 风险：清浏览器数据 / 卸载这个「应用」会把数据一起清掉，界面里目前没有导出/导入入口。
  数据层仍然留着 `Store.exportJSON()` / `Store.importRows()`（见 `js/store.js`），哪天想加回「备份 / 导入」按钮，接上这两个函数就行。

## 五、目录结构

```
sleep-aquarium/
├── index.html                主应用（鱼缸 / 今晚几点睡 / 锁定 / 记录 / 图鉴）
├── widget.html               精简鱼缸预览页（配合桌面网页小组件用）
├── manifest.webmanifest      PWA 配置
├── sw.js                     离线缓存
├── css/style.css
├── js/store.js               数据层 + 结算引擎
├── js/aquarium.js            Canvas 水族馆渲染引擎
├── js/app.js                 界面与交互
├── icons/                    应用图标（脚本生成，别手改）
├── tools/make_icons.py       图标生成脚本（纯标准库）
├── tools/test_store.js       结算引擎回归测试（50 项）
├── tools/test_migrate.js     老数据迁移回归测试（13 项）
└── .github/workflows/pages.yml   推 main 自动跑测试 + 发布到 Pages
```

本地自测（不需要任何 npm 依赖，只要 Node）：

```bash
node tools/test_store.js
node tools/test_migrate.js
```

## 六、想改规则？

- **鱼的数量上限**：`js/store.js` 顶部的 `MAX_FISH = 24`；
- **每晚奖励**：写死在 `js/store.js` 的 `applyResult` 里，达成一晚就是 +1 条；
- **结算时机**：起床即结算，见 `js/store.js` 的 `timingFor` 与 `settleAll`；
- **结算力度**：`js/store.js` 里 `applyResult` 中的那几个 0.055 / 0.09 / 0.045 / 0.12 系数；
- **几点的睡眠算「晚睡」**：`js/store.js` 顶部的 `LATE_LIMIT_MIN = 40`；
- **鱼的种类**：`js/store.js` 里的 `SPECIES` 数组，改颜色和体型就行。
- **图标**：`tools/make_icons.py`，改完跑 `python tools/make_icons.py`。
